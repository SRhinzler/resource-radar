# Bundled media helpers

This folder contains the pinned Windows x64 media helpers shipped with Resource Radar:

- `yt-dlp.exe` — public platform metadata and media extraction
- `ffmpeg.exe` and `ffprobe.exe` — stream merging and media inspection
- `deno.exe` — the JavaScript runtime used by current yt-dlp YouTube extraction

The installer includes these files automatically. Users should not install or copy any additional application. `manifest.json` records the versions, sources, and SHA-256 values; `THIRD_PARTY_NOTICES.md` records the redistribution notices.
